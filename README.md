SewJoy
SewJoy is a dedicated web application designed for sewing enthusiasts to organize, track, and manage their sewing projects and materials in one place. 
Whether you are a beginner or a pro, SewJoy helps you turn your creative ideas into finished garments with ease.

Status: 🚧 This project is currently under development.

🚀 Key Features (Planned)
Project Tracking: Manage your sewing queue from inspiration to completion.

Fabric & Pattern Library: Keep a digital inventory of your stash and pattern collection.

Measurement Profiles: Store measurements for yourself, friends, or family.

Task Management: Break down complex projects into simple, manageable steps.

🛠️ Tech Stack
Frontend: React / Vite

Backend: Node.js (Express)

Database: PostgreSQL / Supabase

Testing: Playwright (Planned)

🏁 Getting Started
To get a local copy up and running, follow these steps:

Clone the repository:

Bash
git clone https://github.com/LuGue-coder/sewjoy.git
Install dependencies:

Bash
cd sewjoy
npm install
Run the development server:

Bash
npm run dev
